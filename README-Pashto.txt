دریر خصوصي عالي لېسې ویب‌سایټ — د GitHub Pages لپاره

فایلونه:
- index.html: د ویب‌سایټ ټول کوډ
- school-logo.jpg: ستاسو د ښوونځي لوګو

په Android موبایل کې د خپرولو لنډ ګامونه:
1. د Chrome له لارې github.com ته ننوځئ او خپل حساب ته لاګ‌ان شئ.
2. د + نښه یا New repository وټاکئ.
3. د repository نوم ولیکئ: dareer-school-website
4. Public وټاکئ او Create repository کلیک کړئ.
5. په repository کې Add file > Upload files وټاکئ.
6. index.html او school-logo.jpg دواړه اپلوډ کړئ او Commit changes وکړئ.
7. Settings > Pages ته لاړ شئ.
8. Build and deployment کې Deploy from a branch وټاکئ.
9. Branch: main او folder: /(root) وټاکئ، بیا Save وکړئ.
10. څو دقیقې وروسته به ستاسو ویب‌سایټ عموماً په دې بڼه وي:
    https://YOUR-USERNAME.github.io/dareer-school-website/

مهم:
- YOUR-USERNAME د خپل GitHub کارن‌نوم په نوم بدل کړئ.
- فورمه اوس یوازې نمونه ده؛ معلومات نه لېږي او نه یې خوندي کوي.
- د ښوونځي حقیقي ټیلیفون، دقیق ادرس، اعلانونه، پایلې او عکسونه باید د ادارې له تایید وروسته ورزیات شي.
- د زده‌کوونکو شخصي پایلې یا حساس معلومات په عامه ویب‌سایټ کې مه خپروئ.
